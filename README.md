# 🌸 A Little World of Comfort 💗
### A 3D Interactive Period Care & Love Website

A handcrafted digital sanctuary built with genuine love, thoughtful care, and cinematic 3D visual storytelling for when she needs comfort, rest, and unconditional warmth.

---

## ✨ Features & Experiences

1. **🧸 Hero Section — A Warm Hug**
   - Interactive 3D teddy bear holding a pulsing, glowing 3D heart.
   - Floating pastel flowers and drifting glowing particles.
   - Mouse parallax tracking where the teddy gently follows cursor movement.
   - Tapping the teddy triggers a joyful hop, confetti shower, and loving micro-affirmations.
   - Main heading: *"Hey, my favorite human... ❤️"* and *"Open Your Little Surprise 💗"* action.

2. **💌 Deep Emotional Message Section — Handwritten Reveal**
   - Elegant parchment letter styling with Playfair Display and Caveat handwritten typography.
   - Word-by-word reveal animation replicating a real letter being penned with care.
   - Wax seal and postal badge motifs.
   - Play/pause reading controls and instant "Read Full Letter" option.

3. **🌸 Interactive 3D Comfort World**
   - Full Three.js WebGL scene with procedural 3D models.
   - Cute articulable teddy bear, fluttering 3D butterflies with realistic wing flaps, drifting soft clouds, and floating petals.
   - Floating 3D heart that smoothly tracks cursor coordinates with subtle tilt.
   - **"Send Me A Virtual Hug 🤗"** button:
     - Teddy opens his arms wide in a warm embrace.
     - Glowing hearts float upward from his chest.
     - Heartfelt modal appears: *"Imagine the biggest hug from me. I'm right there with you."*

4. **💗 Your Little Comfort Menu — "What does my princess need today?"**
   - 6 Interactive self-care options:
     - 🧸 **A virtual hug**: Squeeze dispenser with unlimited extra hug counter.
     - 🍫 **Chocolate therapy**: Interactive box of artisan chocolates you can tap to eat.
     - 🌷 **A little appreciation**: Deep reminders of how precious and beautiful she is.
     - 🎵 **Some peaceful music**: Calming pentatonic lullaby synthesizer.
     - 💌 **A love letter**: Intimate handwritten card.
     - 💤 **Permission to do absolutely nothing**: Certified stamped rest pass.

5. **🍵 Period Care & Calming Station**
   - **Heating Pad Timer**: 15-minute gentle warm compress relaxation timer with soothing countdown.
   - **Warm Tea & Water Tracker**: Visual water glasses tracker to encourage gentle hydration.
   - **Real-Time Mood Hug Box**: Instant tender responses for cramps, fatigue, or mood swings.

6. **✨ Reasons Why You're Special**
   - 6 Floating 3D heart cards with authentic physics-based mouse tilt (`rotateX`, `rotateY`, holographic sheen).
   - Showcases the 6 heartfelt reasons why she is cherished on her best and hardest days.

7. **🎁 A Little Surprise — 3D Interactive Gift Box**
   - Handcrafted 3D Gift Box with satin ribbon in a lighted pedestal scene.
   - Clicking the box triggers realistic lid opening, ribbon untie, and a burst of glowing 3D hearts, petals, and confetti.
   - Displays the full-screen heartfelt promise message.

8. **🌙 Final Section — Cinematic Starry Sky**
   - Dreamy night sky with 3D crescent moon, twinkling 3D starfield, shooting stars, and an ethereal glowing 3D heart.
   - Heartfelt closing note: *"Periods last a few days, difficult moments pass, but my care for you isn't limited to your good days... I love you, baby. ❤️"*
   - **"Replay Our Little World"** button with smooth star-trail scroll to the top.

9. **🎶 Ambient Audio & Magical Particle Cursor**
   - Built-in Web Audio API soothing pentatonic chime/lullaby synthesizer (zero external audio file dependency issues).
   - Delicate floating hearts and sparkles trailing behind cursor/finger touch.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **3D Graphics**: Three.js (Procedural Geometries, MeshStandardMaterials, Custom Lighting, PCFSoftShadows, Raycasting)
- **Animations**: Framer Motion + Canvas Confetti
- **Styling**: Tailwind CSS + Custom Glassmorphism & KaTeX/Typography
- **Icons**: Lucide React

---

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Builds optimized production files to `dist/`.

### 3. Preview Production Build
```bash
npm run preview
```
